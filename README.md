---

## ✨ Sobre o Projeto

O **Leitores de Papel** é um sistema web criado por **Alan Prates** e **Daniel Monteiro** com o objetivo de promover a cultura da leitura entre estudantes e comunidade do IFBA Ilhéus, oferecendo uma plataforma interativa para registro e compartilhamento de leituras.

---

## 🚀 Funcionalidades

- 📚 Cadastro e listagem de livros
- 👤 Gerenciamento de usuários leitores
- ⭐ Avaliações e resenhas de livros
- 🔍 Busca e filtragem do acervo
- 📊 Painel administrativo
- 🔐 Sistema de autenticação de usuários

---

## 🗂️ Estrutura do Projeto

```
Leitores-de-papel-ifba-Ilheus/
├── actions/        # Ações do sistema
├── admin/          # Painel administrativo
├── assets/         # Arquivos estáticos (CSS, JS, imagens)
├── config/         # Configurações do banco e app
├── docs/           # Documentação e screenshots
├── includes/       # Componentes reutilizáveis
├── lib/            # Bibliotecas auxiliares
├── public/         # Páginas públicas
├── user/           # Área do usuário
├── index.php       # Ponto de entrada
└── setup_database_full.php  # Setup do banco
```

---

## 🚀 Como rodar localmente

```bash
# 1. Clone o repositório
git clone https://github.com/AlanPrates/Leitores-de-papel-ifba-Ilheus.git
cd Leitores-de-papel-ifba-Ilheus

# 2. Configure o banco de dados
# Importe o arquivo setup_database_full.php ou execute via navegador

# 3. Configure as credenciais
# Edite config/ com seus dados de banco de dados

# 4. Rode com servidor local (XAMPP, WAMP ou PHP built-in)
php -S localhost:8000
```

**Pré-requisitos:** PHP 7.4+, MySQL 5.7+
